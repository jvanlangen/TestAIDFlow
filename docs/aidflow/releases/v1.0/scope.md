# Release scope: v1.0

## Release goal

Deliver the approved meal and grocery planning capability for the user's
household, with the requested desktop and mobile platform coverage.

## Included feature IDs

- `F-0001` — Meal and grocery planning.

## Excluded or deferred feature IDs

- None. No other feature proposals are currently in the approved backlog.

## Dependencies and ordering

- `F-0001` has no dependency on another feature.
- Its shared ingredient list, meal definitions and grocery-list calculation are
  included in the same feature.

## Release-level acceptance criteria

- The release satisfies the approved Definition for `F-0001`.
- The household can define meals using shared ingredients and one-person
  ingredient quantities, select meals and people counts, and obtain a grocery
  list with repeated ingredients combined using consistent units.
- The feature runs on macOS/OS X, Windows, Linux, Android and iOS/iPhone.
